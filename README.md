# IA LUCRATIVA V1.2

## Novidades
- 6 ferramentas clicáveis e funcionais.
- Interface de ferramenta ativa.
- API interna em `/api/generate`.
- Integração opcional com IA real por `OPENAI_API_KEY`.
- Modo demonstração automático quando a chave não está configurada.
- Botões de destaque e navegação funcionando.

## Rodar localmente
```bash
npm install
npm run dev
```

## Vercel
Adicione `OPENAI_API_KEY` nas Environment Variables. Opcionalmente adicione `OPENAI_MODEL`.

Nunca envie a chave para o GitHub.
