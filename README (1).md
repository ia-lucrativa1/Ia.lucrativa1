# IA LUCRATIVA V1.1
Base Next.js preparada para Vercel.

## Local
npm install
npm run dev

## Vercel
Envie para GitHub, importe o repositório na Vercel e clique em Deploy.
A Vercel detecta Next.js automaticamente.
